About the project

PantryChef is a personal project built with React and Vite. You type in the ingredients you already have, and it searches real recipes through TheMealDB API — filtering out anything below a 50% ingredient match so you only see recipes you can actually make.

Results are ranked by ingredient match score, cooking time, and beginner-friendly difficulty so you always get the most practical option first. Each recipe card shows missing ingredients upfront so you know exactly what you need.

The app also includes a Pantry Mode for common staples, a shopping list for missing ingredients, and saves your data locally so nothing is lost between sessions.

Key features

  • 01Ingredient tags — quick add and remove ingredients
  • 02Smart matching — 50% minimum match filter via TheMealDB
  • 03Ranked results — sorted by match score, time & difficulty
  • 04Recipe details — owned vs missing ingredients highlighted
  • 05Shopping list — auto-generated from missing ingredients
  • 06Pantry mode — pre-load common staples instantly
  • 07Local storage — ingredients, favourites & list saved between sessions

About the project

SecureBank is a personal cybersecurity project — a simulated online banking application built to demonstrate secure coding practices using Python and Flask. The focus wasn't on building banking features, but on getting security right from the ground up.

Every vulnerability was considered during development — from password hashing with bcrypt to CSRF token validation on every form, and a full Content Security Policy configured with Flask-Talisman to mitigate XSS and clickjacking.

The app was tested using OWASP ZAP, and all identified issues including missing CSRF protection, weak CSP and missing security headers were resolved before completion.

Security features

  • 01bcrypt password hashing — passwords never stored in plain text
  • 02CSRF protection — every form requires a valid token via Flask-WTF
  • 03Content Security Policy — mitigates XSS and clickjacking via Flask-Talisman
  • 04Secure session management — protected routes via Flask-Login
  • 05Password complexity validation — enforced server-side, not just client-side
  • 06OWASP ZAP tested — all flagged issues identified and resolved
  • 07HTTP security headers — additional browser protections configured

About the project

A fully functional Android application built for a university assessment, showcasing a dashboard of music albums with details such as artist name, album title, release year, and genre.

Users authenticate through a login screen before accessing the dashboard. Album data is fetched from a remote API using Retrofit, with Hilt handling all dependency injection throughout the app.

The project follows MVVM architecture, keeping business logic clean and separated from the UI using ViewModels and LiveData for reactive data updates. Crash rate was reduced by 40% through proper session handling and DI.

Key features

  • Login screen — authenticates via API and returns a keypass
  • Album dashboard — lists albums fetched from a REST API
  • Album details screen — full info on each selected album
  • Hilt DI — reduced app crashes by 40%
  • MVVM architecture — clean separation of UI and logic
  • Retrofit — handles all network requests
  • LiveData — reactive UI updates

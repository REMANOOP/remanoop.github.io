About the project

A fully functional Android application built for a university assessment, showcasing a dashboard of music albums with details such as artist name, album title, release year, and genre.

Users authenticate through a login screen before accessing the dashboard. Album data is fetched from a remote API using Retrofit, with Hilt handling all dependency injection throughout the app.

The project follows MVVM architecture, keeping business logic clean and separated from the UI using ViewModels and LiveData for reactive updates. Crash rate reduced by 40% through proper session handling and DI.

Key features

  • 01Login screen — authenticates via API and returns a keypass
  • 02Album dashboard — lists albums fetched from a REST API
  • 03Album details — full information on each selected album
  • 04Hilt DI — reduced app crashes by 40%
  • 05MVVM architecture — clean separation of UI and logic
  • 06Retrofit — handles all network requests cleanly
  • 07LiveData — reactive UI updates throughout
